# Superpowers Skills - Desktop Launcher Edition

This collection provides structured workflows for developing the Windows Minecraft launcher.

## Available Skills

### Core Skills
- `[[brainstorm]]` - Clarify intent before building (RED/GREEN/REFACTOR for launcher features)
- `[[plan]]` - Break work into 2-5 minute tasks using git worktrees
- `[[subagent]]` - Delegate tasks to specialized agents
- `[[review]]` - Code review against plan requirements

### Launcher-Specific Skills
- `[[test-tdd]]` - Test-driven development for Kotlin/Java code
- `[[windows-compat]]` - Windows-specific considerations and testing
- `[[mod-loader]]` - Fabric, Quilt, Forge, NeoForge integration patterns

## Workflow Overview

1. **Brainstorm** - Define clear requirements for launcher features
2. **Plan** - Create git worktrees and break into small tasks
3. **Develop** - Write tests first, then implementation
4. **Review** - Verify against plan, run tests
5. **Finish** - Verify tests pass, merge/close

Mandatory workflows. Follow them to ensure quality and consistency.
